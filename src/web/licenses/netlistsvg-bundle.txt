Code inside netlistsvg 1.0.2's prebuilt browser bundle

built/netlistsvg.bundle.js compiles in the npm packages below.  The bundle does
not record their versions, so the texts come from each package's npm tarball
(registry.npmjs.org/<name>/-/<name>-<version>.tgz) at the version listed;
lodash states its own.
